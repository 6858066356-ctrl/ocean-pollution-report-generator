# Ocean Pollution Impact Report Generator (OPIRG)

**Making ocean pollution information easier to record, organize, and understand.**

## About the Project

The Ocean Pollution Impact Report Generator (OPIRG) is a web-based environmental reporting project designed to make documenting ocean pollution easier and more organized.

The website allows users to submit information about pollution observations, select their locations through an interactive map, and generate structured environmental reports.

The main goal is to support environmental awareness by making pollution information easier to understand and communicate.

## Project Objectives

- Simplify the process of recording ocean pollution observations.
- Generate organized pollution reports based on user submissions.
- Provide information about potential environmental impacts.
- Suggest possible pollution prevention and cleanup actions.
- Improve public awareness of ocean pollution.

## Key Features

### 1. Pollution Reporting Form
Users can submit pollution information, including:
- Pollution type
- Quantity
- Debris size
- Location name
- Observation date
- Additional observations

### 2. Interactive Location Map
Users can select the location of pollution directly on a map. The system records the latitude and longitude coordinates.

### 3. Automatic Report Generation
The website organizes submitted information into a structured pollution observation report.

The report includes:
- Pollution information
- GPS coordinates
- Observations
- Environmental impact
- Recommendations

### 4. Public Pollution Map
Displays pollution observations through map markers so users can explore reported pollution locations.

### 5. Pollution Report Cards
Shows submitted pollution information in organized cards, including the pollution type, location, quantity, and date.

## How OPIRG Works

The project follows three main steps:

1. **Observe:** Users enter information about the pollution they have found.
2. **Generate:** The website organizes the submitted information into a report.
3. **Understand:** Users review the pollution details, possible environmental impacts, and recommendations.

## Technologies Used

- HTML – Website structure
- CSS – Website styling and layout
- JavaScript – Interactive features and report generation
- Leaflet – Interactive mapping
- OpenStreetMap – Map data
- GitHub – Source code management
- GitHub Pages – Website hosting

## Project Limitations

The current version uses predefined text for report generation rather than a fully integrated Generative AI model. Environmental impact explanations are also general and depend on the information provided by users.

## Future Improvements

- Integrate a Generative AI model for more detailed environmental analysis.
- Provide more specific pollution prevention recommendations.
- Add a shared online database to store and share reports.
- Include more environmental research sources.
- Improve geographical data visualization.
- Enhance the overall user interface and user experience.
